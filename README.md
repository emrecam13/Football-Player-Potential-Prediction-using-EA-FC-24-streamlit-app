# Football Player Potential Prediction App

A Streamlit web application to predict the future potential of football players using machine learning models.  
Built as part of an MSc Data Science & Artificial Intelligence dissertation at Bournemouth University.

---

## 🚀 Features

1. **Overview & Data Summary**  
   - Explore raw and processed player datasets  
   - View summary statistics, distributions, and sample model outputs  

2. **Model Evaluation & Comparisons**  
   - Precomputed cross-validation metrics (RMSE, MAE, R²) for four models  
   - Compare Linear Regression, LightGBM, SVR, and XGBoost across four position groups  

3. **Interactive Prediction**  
   - Enter 11 key attributes for a chosen position  
   - Instantly predict player potential with your selected model  

4. **Build Your Own Plot**  
   - Customize histograms, boxplots, or scatter plots on any numeric result column  
   - Group by position or preferred foot  

5. **About & Survey**  
   - Project background, guidelines, and detailed feature guide
